StrokkCommands is hosted on the [eldonexus](https://eldonexus.de). It is split into platform-specific modules:

### Paper Modules
| Module Name                 | Description                                                           |
|-----------------------------|-----------------------------------------------------------------------|
| annotations-paper           | Annotations for Paper plugins (includes common annotations).          |
| processor-paper             | Annotation processor for Paper plugins.                               |

### Velocity Modules
| Module Name                 | Description                                                           |
|-----------------------------|-----------------------------------------------------------------------|
| annotations-velocity        | Annotations for Velocity plugins (includes common annotations).       |
| processor-velocity          | Annotation processor for Velocity plugins.                            |

### Common Modules (included automatically)
| Module Name                      | Description                                                      |
|----------------------------------|------------------------------------------------------------------|
| annotations-common               | Core annotations shared across platforms.                        |
| annotations-common-permission    | Permission-related annotations (`@Permission`).                  |

This separation is made with a very specific purpose in mind: To include only the most necessary classes in your
project classpath. Since the `processor` modules only contain internal logic classes (which can have similar
names as Brigadier itself), having them included in the classpath would make development experience very annoying.

<br/>

Therefore, adding the dependency would look like this, depending on your build-system.
The versions here are automatically fetched and thus always up to date.

## Adding the repository
First, we have to add the repository:

<Tabs syncKey="build-system">
  <TabItem label="Gradle">
    ```kts
    repositories {
      maven {
        id = "eldonexus"
        url = "https://eldonexus.de/repository/maven-public/"
      }
    }
    ```
  </TabItem>
  <TabItem label="Maven">
    ```xml
    <repositories>
      <repository>
        <id>eldonexus</id>
        <url>https://eldonexus.de/repository/maven-public/</url>
      </repository>
    </repositories>
    ```
  </TabItem>
</Tabs>

<br/>
Next up we add the dependency:

## Paper

<Tabs syncKey="build-system">
  <TabItem label="Gradle">
    For Gradle, we simply add the annotations module as a `compileOnly` and the processor module as a
    `annotationProcessor` dependency.

    ```kts replace
    dependencies {
      compileOnly("net.strokkur:annotations-paper:\{LATEST_COMMANDS_RELEASE}")
      annotationProcessor("net.strokkur:processor-paper:\{LATEST_COMMANDS_RELEASE}")
    }
    ```
  </TabItem>
  <TabItem label="Maven">
    For Maven, we first have to add the annotation module as a dependency, with scope `provided` so that
    the annotations do not get included in the output jar.

    ```xml replace
    <dependencies>
      <dependency>
        <groupId>net.strokkur</groupId>
        <artifactId>annotations-paper</artifactId>
        <version>\{LATEST_COMMANDS_RELEASE}</version>
        <scope>provided</scope>
      </dependency>
    </dependencies>
    ```

    Finally, we modify the compiler plugin and add a new annotation processor path for our processor module.
    ```xml replace
    <pluginManagement>
      <plugins>
        <plugin>
          <groupId>org.apache.maven.plugins</groupId>
          <artifactId>maven-compiler-plugin</artifactId>
          <version>3.6.1</version>
          <configuration>
            <annotationProcessorPaths>
              <!-- Add annotation processor -->
              <annotationProcessorPath>
                <groupId>net.strokkur</groupId>
                <artifactId>processor-paper</artifactId>
                <version>\{LATEST_COMMANDS_RELEASE}</version>
              </annotationProcessorPath>
            </annotationProcessorPaths>
          </configuration>
        </plugin>
      </plugins>
    </pluginManagement>
    ```
  </TabItem>
</Tabs>

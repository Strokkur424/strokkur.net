StrokkCommands is hosted on the [eldonexus](https://eldonexus.de).
It is split into two separate modules:

| Module Name          | Description                                                           |
|----------------------|-----------------------------------------------------------------------|
| annotations-velocity | This module holds the annotations for you to add in your source code. |
| processor-velocity   | This module only holds the annotation processor.                      |
